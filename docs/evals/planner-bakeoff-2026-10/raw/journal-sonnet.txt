## Risks and guards

- Schema drift: no store, migration, or version edits. The tests above enforce this.
- Relabeling: refuse any change that makes a Runtime run resolve through the webhook-run lookup.
- Silent widening: the improvement report must not start mixing in Runtime runs without a deliberate decision.
- Stub retrospectives: refuse to emit an empty or fake export for Runtime runs. Absence is the honest state.
- Doc drift: the note must not say "shipped" or "planned for date X". It says "blocked on S5".
- Wrong tests: the refusal tests describe today's behavior. When the store lands, the writer must update them deliberately, not delete them.
- Cost: no model-driven work is needed. Verify with `npm run verify`.
